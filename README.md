# EXP 5: COMPARATIVE ANALYSIS OF DIFFERENT TYPES OF PROMPTING PATTERNS AND EXPLAIN WITH VARIOUS TEST SCENARIOS	
## Aim
To test and compare how different prompting patterns respond to various prompts such as naïve prompts (broad or unstructured) and basic prompts (clear, refined, and structured) across multiple scenarios. Analyze the quality, accuracy, and depth of the generated responses.

---

## AI Tools Required
- ChatGPT

---

## Explanation

### Types of Prompting Patterns

### 1. Naïve Prompt
A naïve prompt is broad, simple, or unclear and provides very little context or instruction to the AI model.

### 2. Basic Prompt
A basic prompt is structured and refined. It clearly specifies:
- The task
- Expected output
- Format
- Context or constraints

Structured prompts help AI generate more accurate and meaningful responses.

---

## Test Scenarios

The following scenarios were selected for comparison:

1. Creative Story Generation  
2. Factual Question Answering  
3. Summarization  
4. Advice and Recommendation  

For each scenario:
- A naïve prompt was tested
- A basic prompt was tested
- Responses were analyzed based on:
  - Quality
  - Accuracy
  - Depth
  - Clarity
  - Creativity

---

## OUTPUT

## Scenario 1 – Creative Story Generation

| Prompt Type | Prompt | Output Summary |
|---|---|---|
| Naïve Prompt | Write a story about space. | Generated a short generic story with limited creativity and details. |
| Basic Prompt | Write a 200-word science fiction story about a young astronaut discovering a hidden planet. Include emotions, dialogue, and a surprising ending. | Generated a detailed and engaging story with proper narration, dialogue, and creativity. |

---

## Scenario 2 – Factual Question Answering

| Prompt Type | Prompt | Output Summary |
|---|---|---|
| Naïve Prompt | Explain AI. | Returned a short general explanation with minimal detail. |
| Basic Prompt | Explain Artificial Intelligence in simple terms with examples in healthcare, education, and banking. | Generated a detailed explanation with real-life examples and better clarity. |

---

## Scenario 3 – Summarization

| Prompt Type | Prompt | Output Summary |
|---|---|---|
| Naïve Prompt | Summarize machine learning. | Produced a short and vague summary. |
| Basic Prompt | Summarize machine learning in 5 points suitable for engineering students. | Produced concise, organized, and educational summary points. |

---

## Scenario 4 – Advice and Recommendation

| Prompt Type | Prompt | Output Summary |
|---|---|---|
| Naïve Prompt | How to study better? | Returned general advice with limited usefulness. |
| Basic Prompt | Suggest a practical study plan for a second-year engineering student preparing for exams with limited time. | Generated a realistic, structured, and practical study strategy. |

## Findings

- Basic prompts consistently generated better responses than naïve prompts.
- Structured prompts improved:
  - Quality
  - Accuracy
  - Depth
  - Creativity
  - Clarity
- Naïve prompts worked only for simple tasks but lacked detailed output.
- Adding context, formatting instructions, and examples significantly improved ChatGPT’s performance.

---



## Result

The comparative analysis of different prompting patterns was executed successfully. The experiment demonstrated that structured and refined prompts produce significantly better outputs in terms of quality, accuracy, creativity, and depth compared to naïve prompts.
